# External tools

The MIT license in this repository covers its original scripts, analysis code, and authored documentation. External tools remain subject to their own licenses. No third-party tool source code or binaries are bundled here; raw logs record their output and identify the tested versions.

- [rdma-core](https://github.com/linux-rdma/rdma-core/tree/v50.0): verbs/CM utilities and userspace providers. See its upstream license files and per-file notices.
- [perftest](https://github.com/linux-rdma/perftest): RDMA microbenchmarks. See upstream license notices.
- [NVIDIA nccl-tests](https://github.com/NVIDIA/nccl-tests/blob/afd59abab774a6a4b492eb344bd0c845a0b7bb4d/LICENSE.txt): collective benchmarks, BSD 3-Clause license.
- [NVIDIA NCCL](https://github.com/NVIDIA/nccl): collective communication library; see the license accompanying the installed package.
- [Open MPI](https://www.open-mpi.org/community/license.php): process launch and MPI support.
- [iperf3](https://github.com/esnet/iperf): TCP throughput baseline.
- [Matplotlib](https://matplotlib.org/stable/project/license.html): optional figure generation.
